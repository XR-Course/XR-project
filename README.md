# About Project
This is a Fire safety simulation where the environment is an office. To start with you need to identify 3 electrical hazards, where afterwards one of them will caught fire. You will have 2 options. Either to evacuate directly to nearest exit, or extinguish the fire first and then evacuate.
to play the simulation build the Scene named "Office Training"
